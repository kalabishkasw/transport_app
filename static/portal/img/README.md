# Зображення для головної сторінки порталу

Збережіть сюди такі файли (точні імена):

## fleet.jpg
Фото автобусів автопарку (наприклад Mercedes Tourismo шеренгою).
Рекомендована роздільність 1280x720+ або шире, формат JPG.
Використовується у блоці «Сучасний автопарк».

## city_prague.jpg, city_warsaw.jpg, city_berlin.jpg
## city_budapest.jpg, city_vienna.jpg, city_krakow.jpg
Фото міст для блоку «Популярні напрями».
Розмір 600x400+, формат JPG, портретно/ландшафтно орієнтоване.

## Як додати фото

1. Збережіть зображення на робочий стіл під вищезазначеними іменами
2. Скопіюйте файли у цю папку: `transport_app/static/portal/img/`
3. Перезавантажте сторінку у браузері (Ctrl+F5)

## Що буде якщо файлу нема

Шаблон тоді сховає `<img>` тег і покаже красивий градієнтний фон з назвою міста (для карток) або з іконкою автобуса і написом «Mercedes-Benz Tourismo» (для блоку автопарку). Тобто сторінка не «зламається», а виглядатиме професійно навіть без зображень.

## Звідки взяти фото безкоштовно

- unsplash.com (пошук "Budapest", "Krakow", "Mercedes Tourismo")
- pexels.com (так само)
- commons.wikimedia.org (тематичний пошук)

Завантажуйте у JPG, бажано від 1000px по ширині для якості Retina.
